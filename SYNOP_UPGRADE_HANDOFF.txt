2.1 ALUR UTAMA SCRIPT LAMA (main)
  login -> klik_tombol_oke_popup (pyautogui) -> memilih_stasiun
  -> memilih_tanggal (tanggal UTC = waktu lokal - 7 jam; dipilih SEKALI)
  -> loop selamanya:
       baca Excel -> untuk tiap baris:
         baca ulang Excel; bandingkan perubahan baris
         lewati jika waktu_eksekusi sudah lewat
         countdown sampai waktu_eksekusi (cek perubahan Excel tiap 2 detik)
         loop recovery per baris (maks MAX_ROW_RECOVERY = 2):
           isi_per_jam -> Fill_AWS_Digi -> memilih_observer (sekali)
           -> tunggu form (#present_weather_ww; jika tidak muncul =
              SESSION_RECOVERY_NEEDED -> recover_session)
           -> isi_data -> Preview -> Preview_OK
              (fallback ww 10->05 jika gagal & ww=10)
           -> SEND_SEND_SUBMIT -> SEND_INASWITCH_SUBMIT
              (fallback SEND_INASWITCH) -> SEND_GTS -> SEND_GTS_OK
         error biasa: lewati baris
       setelah semua baris: tunggu 10 detik, baca ulang Excel.
  Observer: nama diketik lewat input() di terminal saat script dimulai.

2.3 ATURAN BISNIS YANG TERSEMBUNYI DI KODE (harus dipindah ke validator/form)
  R1  cloud_cover_oktas_m = "/ - Cloud" atau "/ -"  -> lewati semua awan,
      langsung isi land_cond.
  R2  cloud_low_type_cl kode "0"  -> awan rendah tidak diisi.
  R3  CL != 0 -> wajib terisi: cloud_low_cover_oktas, awan_rendah_jenis,
      awan_rendah_jumlah, cloud_arah_awan_rendah (kalau kosong -> gagal).
  R4  cloud_low_base_1 opsional (dilewati jika kosong).
  R5  cloud_low_peak_1 & cloud_arah_sebenarnya_1 hanya aktif jika kode jenis
      awan rendah (awan_rendah_jenis) = 8 atau 9. Elevasi (cloud_elevation_1_
      angle_ec) hanya dicoba jika peak_1 berhasil diisi.
  R6  Awan rendah ke-2 hanya jika awan_rendah_2_jenis tidak kosong. Switch
      (label for='775') diklik bila tipe CL berawalan 2, 3, atau 9.
      peak_2/elevasi_2/arah_sebenarnya_2 dilewati jika CL kode = "1".
  R7  CM = "0 -" -> awan menengah dilewati.
  R8  CH = "0 -" -> awan tinggi dilewati; cover_oktas tinggi kosong/"-" ->
      detail awan tinggi dilewati.
  R9  Wajib (gagal = batalkan baris): ww, w1, w2, visibility,
      cloud_cover_oktas_m, CL, CM, CH, land_cond.
  R10 ww = "10" (Mist) yang ditolak (RH < 95%) -> diganti otomatis ke "05"
      (Haze) lalu Preview ulang. (DIPUTUSKAN K2: tetap otomatis + dicatat + notifikasi.)
  R11 [BARU, terverifikasi dari snapshot] Jika CH berkode "/" (mis. "/ - CH
      clouds not visible ..."), web MENONAKTIFKAN NCH, Jenis, Jumlah, Tinggi
      Dasar, Arah awan tinggi lapisan 1 (terisi otomatis). Script lama tetap
      mencoba mengisi cloud_high_cover_oktas -> gagal+menunggu (lihat T18).
      Aturan baru: CH kode "/" => semua kolom awan tinggi diabaikan/dilewati.
  R12 [TERJAWAB F0.5 penuh: lihat 2.8] CM atau CL berkode "/" kemungkinan

  +- snapshots/          screenshot/HTML debug
  +- .env                kredensial (JANGAN di-commit)
  +- config.yaml         path, timeout, jadwal, observer, notifikasi

  dikirim ulang); (4) bisa dilanjutkan setelah crash; (5) setiap perubahan
  data otomatis oleh bot tercatat dan diberitahukan ke pengamat.
